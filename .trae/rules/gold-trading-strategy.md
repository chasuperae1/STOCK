# 黄金量化交易策略规则

## 项目概述

这是一个基于AI的黄金量化交易分析系统，支持实时行情、技术分析、事件驱动策略和博弈论分析。

## 代码规范

### 文件命名
- Python文件使用 snake_case 命名法
- 示例：`gold_analysis.py`, `backtesting.py`

### 代码风格
- 使用4空格缩进
- 保持代码简洁，避免过度注释
- 函数命名清晰，使用动词开头

### 数据源优先级
1. 免费API优先（无需API Key）
2. 模拟数据仅作为最后的fallback
3. 所有数据必须标注来源

## 策略开发规范

### 回测要求
- 必须使用真实历史数据
- 禁止使用模拟数据进行策略评估
- 回测结果必须包含：胜率、夏普比率、最大回撤

### 技术指标
必须实现的指标：
- 均线系统（MA5, MA10, MA20, MA60）
- RSI (14)
- MACD (12, 26, 9)
- 布林带 (20, 2σ)

### 交易信号评分
综合评分范围：-3 到 +3

| 评分 | 建议 |
|------|------|
| ≥ 2 | 🟢 买入/加仓 |
| 1 ~ -1 | 🟡 观望 |
| ≤ -2 | 🔴 卖出/减仓 |

## 数据获取优先级

### 黄金价格API（优先级从高到低）
1. gold-api.com - 实时价格，无需Key
2. xaus.com - 现货价格
3. aurumrates.com - 期货价格，含涨跌

### 新闻API（需要API Key）
1. newsdata.io - 财经新闻
2. MarketAux - 金融新闻
3. GNews - 综合新闻

### 经济日历
- Forex Factory: https://nfs.faireconomy.media/ff_calendar_thisweek.json

## 分析维度权重

| 维度 | 权重 |
|------|------|
| 事件分析 | 25-30% |
| 技术分析 | 25-35% |
| 情绪分析 | 15-20% |
| 基本面 | 15% |
| 波动率 | 10% |
| 博弈论 | 10-15% |

## 风险管理

### 仓位控制
- 激进型：最高30-40%仓位
- 稳健型：最高20-30%仓位
- 保守型：最高10-20%仓位

### 止损建议
- 单次交易最大亏损：2%
- 日内最大亏损：5%

## 输出格式

### 分析报告结构
1. 实时价格（多源验证）
2. 技术指标状态
3. 事件影响评估
4. 情绪分析结果
5. 综合评分与建议
6. 关键价位（阻力/支撑）
7. 风险提示

### 关键价位标注
- 🟥 阻力位
- 🟩 支撑位
- ⚡ 当前价格
