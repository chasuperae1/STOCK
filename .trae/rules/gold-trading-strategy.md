### 二、技术指标计算

#### 2.1 均线系统 (MA)

**公式**：
```
MA(n) = (P₁ + P₂ + ... + Pₙ) / n
```

| 指标 | 公式 | 用途 |
|------|------|------|
| MA5 | 5日均价 | 短期趋势 |
| MA10 | 10日均价 | 短期趋势 |
| MA20 | 20日均价 | 中期趋势 |
| MA60 | 60日均价 | 长期趋势 |

**趋势判断**：
- `MA5 > MA10 > MA20`：上升趋势 ✅
- `MA5 < MA10 < MA20`：下降趋势 🔴
- 其他：震荡整理 ⚡

#### 2.2 RSI相对强弱指标

**公式**：
```
RSI = 100 - (100 / (1 + RS))
RS = 平均上涨 / 平均下跌

标准周期：14
```

**判断标准**：
| RSI值 | 信号 | 操作 |
|-------|------|------|
| > 70 | 超买 | 🔴 考虑卖出 |
| 50-70 | 偏强 | 🟡 谨慎持有 |
| 30-50 | 中性 | ⚡ 观望 |
| < 30 | 超卖 | 🟢 考虑买入 |

#### 2.3 MACD指标

**公式**：
```
EMA(12) = 12日指数移动平均
EMA(26) = 26日指数移动平均
DIF = EMA(12) - EMA(26)
DEA = DIF的9日指数移动平均
MACD柱 = (DIF - DEA) × 2
```

**判断标准**：
| 信号 | DIF/DEA关系 | MACD柱 | 操作 |
|------|-------------|--------|------|
| 金叉 | DIF上穿DEA | > 0 | 🟢 买入 |
| 死叉 | DIF下穿DEA | < 0 | 🔴 卖出 |
| 背离 | 价格创新低但MACD未创新低 | - | 🟢 买入信号 |

#### 2.4 布林带 (Bollinger Bands)

**公式**：
```
中轨 = MA20
上轨 = MA20 + 2 × σ(20日标准差)
下轨 = MA20 - 2 × σ(20日标准差)
```

**判断标准**：
| 价格位置 | 信号 | 操作 |
|----------|------|------|
| > 上轨 | 超买 | 🔴 考虑卖出 |
| < 下轨 | 超卖 | 🟢 考虑买入 |
| 中轨上方 | 偏强 | 🟡 持有 |
| 中轨下方 | 偏弱 | 🟡 减仓 |

### 四、关键价位计算

#### 4.1 支撑位

```
S₁ = 当日最低价
S₂ = MA20 - 2 × ATR(14)
S₃ = 前一日低点
支撑优先级：S₁ > S₂ > S₃
```

#### 4.2 阻力位

```
R₁ = 当日最高价
R₂ = MA20 + 2 × ATR(14)
R₃ = 前一日高点
阻力优先级：R₁ > R₂ > R₃
```

#### 4.3 止损止盈

```
止损位 = 买入价 × (1 - 2%)
止盈位 = 买入价 × (1 + 3%)
风险收益比 = (止盈位 - 买入价) / (买入价 - 止损位)
最优风险收益比 ≥ 1.5
```

### 五、仓位管理公式

#### 5.1 仓位计算

```
仓位比例 = 账户可用资金 × 风险系数 / 止损幅度
风险系数 = 2%（单次最大亏损）
止损幅度 = |买入价 - 止损价| / 买入价 × 100%
```

#### 5.2 仓位类型

| 账户类型 | 最大仓位 | 适用场景 |
|----------|----------|----------|
| 激进型 | 30-40% | 综合评分≥+2 |
| 稳健型 | 20-30% | 综合评分+1~+2 |
| 保守型 | 10-20% | 综合评分<+1 |

#### 5.3 仓位调整

```
加仓条件：盈利后且趋势延续
减仓条件：亏损达1%或趋势反转
清仓条件：亏损达2%或综合评分<-1.5
```

---

### 六、风险管理公式

#### 6.1 风险度

```
日风险度 = 当日亏损 / 账户总额 × 100%
累计风险度 = ∑(当日亏损) / 账户总额 × 100%
```

#### 6.2 风控阈值

| 指标 | 阈值 | 处理 |
|------|------|------|
| 单次最大亏损 | 2% | 止损出场 |
| 日内最大亏损 | 5% | 停止交易 |
| 连续亏损次数 | 3次 | 暂停策略 |
