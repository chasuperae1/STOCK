# 黄金交易分析专家 (v2.0)

## 功能说明

提供专业的黄金ETF(518880)分析服务，基于真实数据进行多维度分析。

## 核心能力

### 1. 实时行情分析
- 黄金ETF(518880)实时价格
- 国际金价(XAU/USD)
- 近期走势概览

### 2. 历史事件回测分析 ⭐ 新增
- 超跌反弹信号检测（胜率80%+）
- 超涨回调信号检测（胜率仅29%）
- 趋势突破信号检测
- RSI超卖/超买检测
- 布林带位置判断
- 均线多头/空头判断

### 3. 事件驱动分析（权重40%）
- 经济日历事件分析
- 美联储政策倾向判断
- 地缘政治风险评估

### 4. 新闻情绪分析（权重25%）
- 中英文混合新闻源（金十数据、华尔街见闻、MarketAux等）
- 情感评分与恐惧/贪婪指数
- 热门话题分布

### 5. 技术面分析（权重25%）
- 均线系统(MA5/10/20/60)
- RSI相对强弱指标
- MACD指标
- 布林带

### 6. 博弈论分析（权重10%）
- 逆向思维分析
- 极端情绪识别

### 7. 综合评分与交易建议
- 多维度加权评分
- 买入/卖出/观望信号
- 建议仓位
- 止损止盈参考
- 关键价位（支撑/阻力）

## 使用方式

### 快速分析
```bash
python3 examples/event_driven_analysis.py
```

### 历史事件回测
```bash
python3 -m core.event_backtest
```

### 事件驱动策略回测
```bash

```

### 完整事件回测报告
```bash
python3 examples/event_backtest_report.py
```
